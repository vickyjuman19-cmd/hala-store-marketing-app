# HALA Store Marketing App

HALA Homecare Store Marketing and Sales App.

## Features

- Store registration
- Shop owner details
- Store contact number
- Area and pincode
- GPS / Map location
- Shop photo
- Salesman profile
- Employee ID
- Product catalogue
- Product ordering
- Order history
- Visit tracking
- Daily sales dashboard

## Order System

Products can be added to the order without leaving the current page. Added products appear automatically in the order summary below.

## Security

Aadhaar and PAN documents must be stored in secure private storage. Never upload real identity documents, passwords, API keys or database credentials to this public GitHub repository.
